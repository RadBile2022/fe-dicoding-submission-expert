# Screenshot CI/CD yang wajib diganti dengan bukti asli

Folder ini sengaja disiapkan untuk tiga screenshot yang diwajibkan Dicoding.
Jangan membuat atau memakai bukti palsu. Setelah GitHub Actions, Vercel, dan branch protection benar-benar dikonfigurasi, simpan screenshot asli dengan nama:

1. `1_ci_check_error.png` — PR ketika GitHub Actions gagal karena test sengaja dibuat gagal.
2. `2_ci_check_pass.png` — PR setelah test diperbaiki dan seluruh check lulus.
3. `3_branch_protection.png` — halaman PR yang menunjukkan merge diblokir sebelum approving review / required status check terpenuhi.

Hapus README ini bila tidak ingin menyertakannya pada submission akhir.
